# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python command-line program that provides three useful tools: a Simple Calculator, a To-Do List, and a Number Checker.

## Features

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Number Checker:** Identifies whether a number is positive, negative, or zero, and whether it is even or odd.
4. **Interactive Menu:** Allows users to select tools and return to the main menu until they choose Quit.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python toolkit.py
```

## Reflection

Building this project helped me understand how to combine Python concepts into a practical program. The hardest part was creating a menu that continues running and returns after each tool finishes. The To-Do List helped me practise using lists to add, display, and remove items. One challenge was entering information in the correct order when testing the interactive menu. I also learned how to handle invalid inputs without crashing the program. I am proud that I successfully built and tested three different tools. If I had one more week, I would add more tools and improve the program with a graphical user interface.
